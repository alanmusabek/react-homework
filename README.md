# React Self-Promotional SPA

Homework based on the assignment requirements.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## GitHub Pages
This project is Vite-based. For GitHub Pages, enable Pages in the repository settings and deploy the built `dist` folder using your preferred Pages workflow/action.
